# Target product: MoonfalliOS (iOS)

The target-specific detail for [the product](../../product.md).

## Primary persona

A family member holding their phone at the venue. A second persona, the booth OC, uses the same app in OC mode.

## Core jobs to be done

1. When I arrive, I want to join my family by code or QR, so we are registered before the game starts.
2. When the game starts, I want to see my family's role privately, so I know whether to do tasks or hunt.
3. When I play, I want my five tasks and their stamp progress, so I know what is left.
4. When I am a werewolf, I want to kill nearby families and trigger sabotage within the cooldowns, so I can win without being seen.
5. When I am the head of family in a meeting, I want to vote or skip, so my family has a say.
6. When I am a booth OC, I want to stamp a family's task and mark sabotage resolved, so the game state stays correct.
