# Target product: MoonfallAdmin (macOS)

The target-specific detail for [the product](../../product.md).

## Primary persona

The Town Hall OC, running the whole game from a Mac at Lab 1.

## Core jobs to be done

1. When I prepare the event, I want to create the families, join codes and the OC PIN, so players can register.
2. When I start the game, I want roles and task lists assigned automatically, so nobody can bias them.
3. When someone shouts "body", I want to start a meeting with one click, so discussion and voting run on shared timers.
4. When something goes wrong, I want to force-kill, revive, end or pause the game, so the event never stalls.
5. When the lab TVs are on AirPlay, I want a public window with timers and results, so everyone sees the same state without leaking secrets.
6. When I rehearse, I want simulated families and fast-forward, so I can test a full game without 100 people.
